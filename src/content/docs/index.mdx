# Документация для магазина

Документация для магазина: приём платежей, выплаты клиентам, статусы, чеки и
баланс.

## Начало работы

1. Откройте [интеграцию](/doc/v2/integration/) и выберите сценарий.
2. Получите домен, `Shop API key` и `Signature key`.
3. Проверьте магазин через [`GET /shop/info`](/doc/api/shop/03-info/#get-shopinfo).
4. Создайте тестовый ордер и получите финальный статус через callback.

## Выберите задачу

| Задача | Раздел |
| --- | --- |
| Принять платёж с переходом на платёжную страницу | [PayIn Redirect](/doc/v2/red/) |
| Принять платёж на своём UI и сразу получить реквизиты | [PayIn H2H sync](/doc/v2/h2h-sync/) |
| Создать PayIn и выбрать метод позже | [PayIn H2H по шагам — сложный, не рекомендуется](/doc/v2/h2h-step/) |
| Выплатить деньги клиенту | [PayOut H2H](/doc/v2/payout/) |
| Прочитать баланс или вывести средства магазина | [Баланс магазина](/doc/api/shop/02-balances/) |
