---
title: "Ошибки API"
---

Для обработки используйте `statusCode` и `errorCode`, а не текст сообщения.

```json
{
  "statusCode": 400,
  "errorCode": "O10000",
  "errorMessage": "Order status is incorrect"
}
```

Ошибка валидации содержит `message` со списком неверных полей. Её нельзя
исправить повтором того же запроса.

## Основные коды

| Код | Причина | Действие |
| --- | --- | --- |
| `401` | Неверный ключ, среда, тип ключа или IP | Проверить `Authorization`, домен и whitelist |
| `404` | Ресурс не найден | Проверить ID, магазин и среду |
| `S10000` | Магазин неактивен | Остановить операции, обратиться к платформе |
| `S10001` | Недостаточно баланса | Прочитать [`GET /shop/assets`](/doc/api/shop/02-balances/#get-shopassets), не повторять PayOut |
| `S10002` | Платформа не успела вернуть ответ | Найти ордер по `externalOrderId` |
| `O10000` | Действие не подходит статусу | Прочитать ордер и проверить статус |
| `O10001` | Не выбран метод оплаты | Заполнить `payment.type`; `bank` — если выбран конкретный банк |
| `O10002` | Лимит активных ордеров клиента | Не создавать новые ордеры в цикле |
| `O10003` | Ордер не найден | Проверить ID, магазин и среду |
| `O10004` | Недопустимая сумма | Проверить сумму и лимиты |
| `O10005` | Реквизиты не найдены | Предложить другой метод или банк |
| `O10006` | `externalOrderId` уже существует | Использовать существующий ордер |
| `O10007` | Найдено несколько ордеров с одним ID | Использовать внутренний `id`, обратиться в поддержку |
| `O10008` | Клиент заблокирован антифродом | Не повторять запрос автоматически |
| `O10009` | Клиент не в whitelist | Проверить настройки магазина |
| `O10010` | Сумма запрещена антифродом | Изменить сумму или лимиты |
| `O10011` | Провайдер отклонил карту в e-commerce | Не повторять списание автоматически |
| `O10012` | Не принят код подтверждения e-commerce | Не считать платёж успешным; следовать согласованному 3DS/OTP-сценарию |
| `C10000` | Не найден курс | Проверить валюты и exchange-настройки |
| `C10001` | Валюта не найдена | Проверить `currency` |
| `B10000` | Банк не найден | Обновить trade methods и проверить `bank` |
| `P10000` | Тип оплаты не найден | Обновить trade methods и проверить `type` |
| `P10001` | Тип оплаты не включён для магазина | Получить актуальные trade methods или согласовать включение с платформой |
| `T10000` | Trade method недоступен | Повторно запросить список методов |

## Таймаут create-запроса

`S10002`, сетевой таймаут или `500` не означают, что операция не была создана.

1. Найдите ордер по `externalOrderId`.
2. Если найден — продолжайте работу с ним.
3. Если результат остаётся неизвестным — не повторяйте денежную операцию
   автоматически; передайте случай в поддержку.

Всегда задавайте уникальный `externalOrderId` для PayIn и PayOut.

## Когда повторять запрос

| Ситуация | Повтор |
| --- | --- |
| Сетевая ошибка или `5xx` на `GET` | Да, с ограниченным backoff |
| `S10002`/`500` на create | Только после поиска существующего ордера |
| `O10005` | Только с другим методом или банком |
| `O10000` | Только после чтения актуального статуса |
| `401`, валидация, `O10004`, `O10006`, `B10000`, `P10000`, `P10001`, `T10000` | Нет, пока не изменены данные или настройки |

Callback может прийти повторно. Проверяйте подпись и обрабатывайте событие
идемпотентно: [callback и signature](/doc/v2/callback-signature/).
