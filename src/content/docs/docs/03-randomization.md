---
title: "Уникализация суммы"
---

Уникализация помогает назначать реквизиты, когда несколько клиентов создают
PayIn-ордера на одинаковую сумму. Платформа подбирает ближайшую свободную сумму в
настроенных пределах.

## Что учитывать магазину

- В запросе передавайте сумму клиента в `amount`.
- После создания показывайте клиенту только `amount` из ответа: это фактическая
  сумма к оплате.
- `initialAmount` содержит исходную сумму запроса.
- Комиссии и расчёты выполняются от фактического `amount`.
- Если подходящую сумму и реквизиты найти не удалось, обработайте ошибку
  [`O10005`](/doc/docs/02-api_error_guide/#основные-коды).

Пример: магазин запросил `1000`, а платформа назначила `1010`:

```json
{
  "initialAmount": 1000,
  "amount": 1010,
  "currency": "RUB",
  "status": "customer_confirm"
}
```

Клиент должен перевести `1010 RUB`, а не `1000 RUB`.

## Настройки

Уникализацию включает поддержка для конкретного магазина.

| Настройка | Назначение |
| --- | --- |
| Диапазон сумм | Минимальный и максимальный `amount`, при которых работает уникализация |
| Отклонение | Допустимое уменьшение и увеличение исходной суммы — в валюте или процентах |
| Шаг | Интервал перебора доступных сумм |

Границы включаются в диапазон. Например, при исходной сумме `1000`, отклонении
`10` и шаге `10` платформа проверяет ближайшие варианты `1010` и `990`.
