Здесь должен жить процесс `RED`: клиент переводится на платёжную страницу платформы, а мерчант управляет только созданием и контролем ордера.

## Когда использовать

- нужен самый короткий запуск;
- UI оплаты можно отдать платформе;
- не требуется показывать реквизиты на своей стороне.

## Базовый флоу

1. Создать ордер.
2. Получить `integration.link`.
3. Перевести клиента на платёжную страницу.
4. Дождаться callback или дочитать статус по `GET`.
