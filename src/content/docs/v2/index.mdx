## Принцип структуры

- В минимальном маршруте держим только то, что нужно мерчанту для запуска.
- В сценарных страницах держим только процесс и шаги интеграции.
- Подробные API-методы и payload reference остаются в `/doc/api/...`.
- `PayIn` разбит по исходным сценариям из оригинальной документации.
- `PayOut` вынесен как отдельный сценарий `Payout H2H`.
- Дополнительные материалы вынесены отдельно, чтобы не перегружать основной маршрут.
- Flow и примеры разделены: сценарии объясняют процесс, а примеры собраны в одной API-странице.
- Все плейсхолдеры `[[BASE_URL]]`, `[[CALLBACK_URL]]`, `[[DOMAIN_URL]]` продолжают поддерживать `?domain=...`.
